# 🚀 دليل تشغيل خادم بايثون (NOVAX Python Backend API)

تم بناء خادم بايثون باستخدام إطار العمل فائق السرعة **FastAPI** وقاعدة بيانات **SQLite** عبر **SQLAlchemy** لربط واجهة الموقع بسيرفر RESTful حقيقي وقوي.

---

## 📦 متطلبات التشغيل

تأكد من تثبيت Python على جهازك (الإصدار 3.9 أو أحدث)، ثم افتح موجه الأوامر (PowerShell أو CMD) في هذا المجلد:

```bash
cd C:\Users\Jenan\.gemini\antigravity\scratch\novax-website\backend
```

### 1. تثبيت الحزم المطلوبة:
```bash
pip install -r requirements.txt
```

---

## ⚡ تشغيل الخادم (Run Server)

شغّل الخادم باستخدام الأمر التالي:

```bash
uvicorn app:app --reload --port 8000
```

سيبدأ الخادم بالعمل على الرابط:
👉 `http://127.0.0.1:8000`

---

## 📚 التوثيق التفاعلي للـ API (Interactive Swagger Docs)

يقدم FastAPI توثيقاً تفاعلياً تلقائياً لتجربة جميع الروابط مباشرة من المتصفح:
- **Swagger UI**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- **ReDoc**: [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)

---

## 🔗 مسارات الـ API المتاحة (Endpoints)

| الوظيفة | الطريقة | المسار | الشرح |
|---|---|---|---|
| **فحص الخادم** | `GET` | `/api/health` | التأكد من أن السيرفر يعمل |
| **تسجيل مستخدم جديد** | `POST` | `/api/auth/register` | إنشاء حساب عضو جديد |
| **تسجيل الدخول** | `POST` | `/api/auth/login` | التحقق من بيانات الدخول |
| **جلب المشاريع** | `GET` | `/api/projects` | استرجاع المشاريع (مع إمكانية الفلترة) |
| **إضافة مشروع جديد** | `POST` | `/api/projects` | حفظ مشروع في قاعدة البيانات |
| **جلب المقالات** | `GET` | `/api/articles` | جلب مقالات المدونة |
| **إرسال رسالة تواصل** | `POST` | `/api/contact` | حفظ رسائل نموذج التواصل |
| **استعراض الرسائل** | `GET` | `/api/contact` | لوحة التحكم لمراجعة الرسائل |

---

## 🔄 الربط مع واجهة المستخدم (Frontend)

في ملف `assets/js/db.js`، النظام مجهز مسبقاً للعمل المزدوج (Hybrid):
1. **الوضع المحلي (Default)**: يعمل بـ IndexedDB تلقائياً دون الحاجة لتشغيل أي سيرفر.
2. **وضع السيرفر**: بمجرد تشغيل خادم بايثون على البورت 8000، يمكنك توجيه الطلبات إليه مباشرة ليصبح التطبيق بنظام Full-Stack متكامل!
